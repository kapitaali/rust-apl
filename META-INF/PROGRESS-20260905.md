## Session 112 (2026-09-05) — Plugin Middleware Hooks

### What was implemented

**`AplPluginHooks` trait:**
- `before_eval(&Expr)` — runs before any expression evaluation, return `Err` to block
- `before_syscmd(&str)` — runs before any `)CMD`, return `Err` to block
- `on_sysvar_change(&str, &ValueP)` — notified when ⎕-vars change

**Integration:**
- `init_plugins()` collects hooks from plugins via `plugin.hooks()` and registers them
- `Environment` stores `Vec<Arc<dyn AplPluginHooks>>`
- `eval()` calls `before_eval` before dispatching
- `syscmd()` calls `before_syscmd` before running commands
- `set()` calls `on_sysvar_change` when ⎕-vars are set

**Tests:** 764 passing (added hook integration tests)

## Session 113 (2026-09-05) — ⎕SEC Security Extension

### What was implemented

**SecurityPlugin:**
- Registers `⎕SEC` sysvar (default 0) and `⎕SEC.VERSION`
- Implements `AplPluginHooks` to enforce security levels
- Uses thread_local storage for current ⎕SEC level

**Security levels:**
- Level 0: all operations allowed
- Level 1: ⍎, ⎕NA, ⎕LOADSO, )COPY, )INP blocked
- Level 2: additionally )SAVE, )LOAD, )OUT, )CONTINUE, ⎕FIO blocked
