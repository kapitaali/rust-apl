### 1. Fixed the recursive-FAC bug (root cause + design fix)

The suspected `last_branch_target` leak between frames was real, but fixing
it revealed a second problem. Two changes:

a) **Branch stack instead of single field** (`Environment.branch_stack:
   Vec<Option<i64>>`): each call frame pushes a None sentinel on entry
   (`frame_base`); its loop only consumes targets pushed ABOVE its sentinel,
   so recursive frames are fully independent. Sentinel truncated on all exit
   paths.

b) **Root cause of the SYNTAX ERROR**: guarded branches were impossible to
   write without dyadic compress! `(N≤1)×4` evaluates to 0 for N>1, and
   →0 means *exit* — so every non-base case exited immediately with R unset.
   Classic APL uses `(N≤1)/4` where `/` is COMPRESS: 1/4 = 4, 0/4 = EMPTY,
   and an empty branch target = fall through. We had reduce-only `/`.

### 2. Dyadic replicate `A/B` — compress (`src/replicate.rs`)

- New `Prim::Replicate`. Tokenizer: `/` after a VALUE token (Num/Str/Name/
  RParen) emits Replicate; `/` after a Prim still merges into Reduce.
  This value-vs-function distinction at tokenize time cleanly separates
  `+/B` (reduce) from `A/B` (compress).
- Semantics: repeat each B element A[i] times; scalar A extends; zero drops;
  all-zero → empty vector (which makes guarded branches fall through).
- 5 tests.
