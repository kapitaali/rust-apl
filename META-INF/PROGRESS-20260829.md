## Non-obvious notes

- Tokenizer bug fixed: `⍥` handling was missing `#[cfg(feature = "unofficial-ext")]`, breaking default build
- `⍥` (U+2365) and `⌸` (U+2328) are NOT in GNU APL 2.0
- `∘` (U+2218, RING OPERATOR) is matrix product in GNU APL, not compose
- Cell::Char holds u32 codepoint; ValueP::char_vector takes &[u32]
- Prim::Power and Prim::Exponential both map to `bif_exponential` for monadic case
- libapl uses thread-local Environment + Mutex-protected callbacks
- C header `install_get_line_from_user_cb` signature fixed to match Rust fn pointer type
- Dyadic A⌸B: A must be a Char scalar representing a Prim glyph (simplified approach)
- XML archive uses custom text format with ²...⁰ char mode and type tags (⁴=int, ⁵=float, ⁶=complex, ³=pointer)
- PackedBool uses bit-packing in u64 words; from_cells/to_cells for conversion
- SmallVec<[Cell; 8]> avoids heap allocation for arrays with ≤8 elements
- Outer product parallelized when result has ≥4096 elements
- Parallel tests sharing the same workspace filename collide; use unique names
