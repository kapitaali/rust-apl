## Non-obvious notes

- `src/ascii_plot.rs` is fully wired — `⎕APLOT vector` renders a bar chart in the REPL
- `ValueInner` now uses `CellStorage` enum — pattern matching on `.ravel` won't work; use `cells()`, `cell_at(i)`, or `ravel_mut()`
- `CellStorage::Fetched` uses `OnceLock` for thread-safe lazy caching; `cells()` auto-materializes
- All quad functions are in `src/quad.rs`. New ones need: (a) `pub fn quad_X(b: &ValueP) -> AplResult<ValueP>`, (b) wire in `match` in `src/parser.rs` eval, (c) add tests
- GTK is not `Send` — must run on its own thread with channel messaging
- `pyo3` requires Python dev headers and a compatible Python version
- `⎕SEC` enforcement is in `src/security.rs` via `check_sec()`
- GNU APL XML format uses custom type tags: `⁴`=Int, `⁵`=Float, `⁶`=Complex, `¹`=hex codepoint
- `config.toml` controls plugin inclusion at compile time
- `crates/apl-ext/` is the extension crate; `crates/demo-plugin/` is the example
